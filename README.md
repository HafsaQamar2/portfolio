## Repository

```
index.html                      page
styles.css                      layout and theme
script.js                       scroll progress, project carousel, rotating notes
cv.html                         print source for the CV
Hifsa_Qamar_CV_formatted.pdf    file behind Download CV
assets/                         portrait and project screenshots
```

There is no build step. GitHub Pages serves this folder from the `main` branch.

## Run it locally

From this folder:

```bash
python -m http.server 8765
```

Then open http://127.0.0.1:8765/

Opening `index.html` directly also works. A local server is better so the CV download and images resolve the same way they do on GitHub Pages.
