What it's like working with me

  1. I take it to a live link

    PayNexus runs on Vercel. The churn model runs on Hugging Face. I would rather show a working path than a folder of screenshots.

  2. I can explain the system

    Years of teaching mean I can describe a schema, a model, or a screen in plain language, then go back and tighten the code.

  3. I keep the data honest

    Superior E-Library uses a normalized MySQL schema. The churn app keeps the model and the encoders together so a new row is scored the same way it was trained.
